# 安定版に進む前に試す

公開候補にはAgentMemoryだけを読み込みます。試用で見つけた不足はタスクへ記録し、範囲を判断して修正します。
標準のカラム名は自由です。必要なら「未着手・作業中・エージェント待ち・判断待ち・保留」などを設定し、実際のIDとの対応をエージェント指示へ記載します。
完了は標準の`closeTask`を使い、閉じたタスクは一覧で`status:closed`、検索では`status:all`を指定します。

## 複数の実作業で確認すること

1. 既存タスクを検索し、該当がなければ作成する。
2. 重要な進展を作業ログに記録し、技術的根拠を詳細履歴へ残す。
3. 人間の採用・却下の理由を判断履歴へ記録する。
4. 区切りでコンテキストと実際のカラム・開閉状態を整合させる。
5. 別のAIセッションでチケットIDから再開し、元の会話なしで次の行動を説明できるか確かめる。
6. 人間がログ・判断を編集/削除し、監査履歴から変更前を確認する。

最低3件の実作業を目安にしますが、件数だけで公開可とは判断しません。
「手で補足しなければ分からなかったこと」「入力できなかったこと」「記録が抜けたこと」を短く残します。

## 安定版の判断

重大なデータ欠落・権限問題がなく、主要な操作が説明どおりできることを確認します。
試用版はGitHub prereleaseとして配布します。結果を確認し、最終ZIPを新規環境で導入してから、人間が安定版化や公式一覧への掲載を承認します。
自動テストや試用開始は安定版化・公式掲載の承認を意味しません。
