# 公開候補の検証

この公開候補は記憶機能・最小UIだけを対象にします。対応確認版はKanboard1.2.55 / SQLiteです。

検証対象：保存・日時・移行・再試行・競合、標準API、認証とプロジェクト権限、手動追記・編集・削除、監査履歴、
標準のタスク概要とMarkdown編集、複数画面幅、別セッションからの復元、プラグイン無効化・再導入・新規ZIP導入。
テストの実行手順は`CONTRIBUTING.md`を参照してください。

初回分離時に保存54、判断日時22、移行9、保存先制限18、API56、メッセージ22、手動フォーム/監査30、編集削除40、標準画面の公開候補UI14項目を通過。
公開ソースだけで無効化・再導入・ZIP新規導入と、作業ログ/判断/コンテキスト/監査履歴の保持も確認した。
外観拡張を戻す検証では既存の画像比較を含む126項目を通過した。これは公開候補の機能追加ではなく、ローカルで元の構成へ戻せることの検証である。

初回の公開候補分離時の実行結果は、生成物の`candidate-manifest.json`とローカルの試用チケットに対応付けます。
実際の業務記録・認証情報・ローカル専用の外観資産は公開物へ含めません。

Firefox/WebKit・実タッチ端末・他Kanboard版/DBは未確認です。
GitHub上のCIの実行結果は[Actions](https://github.com/S0R4Suke/kanboard-agent-memory/actions)で確認できます。
自動テストは複数の実作業による試用の代わりにはしません。`docs/trial.md`に沿って安定版化の前に評価してください。
