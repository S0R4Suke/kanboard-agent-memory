# Changelog

## 0.1.0-rc.1 — Evaluation prerelease

- Task work logs, human decisions and decision timestamps.
- Manual create/edit/delete, stable message IDs and retained audit history.
- Versioned agent context, append-only detailed history and per-task search.
- User-scoped JSON-RPC, request-key deduplication and conflict detection.
- Native task layout and editor retained; records added through a standard hook.
- Python clients, AGENTS.md example, Docker setup and isolated tests.

Initial GitHub prerelease for evaluation with existing Kanboard workflows. Not submitted to the official Kanboard plugin directory.
