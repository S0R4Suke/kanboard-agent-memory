# Security

This plugin uses Kanboard authentication and project permissions. It does not provide a separate authentication service. Agent type and human decision attribution are declarations, not proof of human approval.

Do not include tokens or sensitive work history in a public issue. Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/S0R4Suke/kanboard-agent-memory/security/advisories/new).

Maintainer: S0R4Suke. This is an evaluation prerelease; no response-time commitment is provided. Please include the Kanboard/PHP/database versions, affected plugin version, impact and reproduction steps with secrets removed.

Supported/tested configuration: Kanboard 1.2.55, SQLite, PHP 8.1+. Update Kanboard security releases only after compatibility tests and a backup.
